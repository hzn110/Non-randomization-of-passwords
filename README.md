----------------------------------------------------------------
  프로젝트 소개
----------------------------------------------------------------

우리는 비밀번호를 만들 때 스스로는 무작위라고 생각한다.
하지만 실제 유출 비밀번호 데이터를 들여다보면,
인간은 놀라울 정도로 비슷한 패턴을 반복한다는 사실이 드러난다.

본 프로젝트는 두 가지 관점을 융합하여 이 현상을 탐구한다.

  1) 통계물리학적 관점
     비밀번호를 '거시상태(Macrostate)'로 추상화하고,
     엔트로피·질서변수·볼츠만 통계 등의 개념을 적용하여
     인간 선택의 비무작위성을 정량적으로 분석한다.

  2) 정보보안 관점
     발견된 패턴이 실제 공격 환경(사전 공격, 브루트포스)에서
     어떤 취약점을 만드는지 분석하고,
     강한 비밀번호 설계 원칙을 도출한다.

핵심 연구 질문:
  "인간이 만든 비밀번호는 정말 랜덤할까?
   그리고 그 비무작위성은 정보보안에 어떤 영향을 미칠까?"


----------------------------------------------------------------
  데이터 소개
----------------------------------------------------------------

[ 데이터셋 이름 ]
  RockYou Password Dataset (rockyou_rigorous_behavioral_physics_v2.csv)

[ 원본 데이터 출처 ]
  Kaggle - RockYou Dataset
  https://www.kaggle.com/datasets/wjburns/common-password-list-rockyoutxt

[ 데이터 개요 ]
  - 2009년 소셜 게임 플랫폼 RockYou의 해킹 사고로 유출된
    실제 사용자 비밀번호 약 1,400만 건을 포함한 데이터셋이다.
  - 현재까지도 비밀번호 보안 연구 및 침투 테스트에서
    가장 널리 활용되는 공개 데이터셋 중 하나이다.

[ 주요 파생 변수 (전처리 후 사용) ]
  - password        : 원본 비밀번호 문자열
  - length          : 비밀번호 길이
  - macrostate      : 문자 종류 패턴 (U/L/d/s 조합)
  - shannon_entropy : 섀넌 엔트로피 (문자 분포의 다양성)
  - has_upper / has_lower / has_digit / has_symbol
                    : 문자 종류 포함 여부 플래그

[ 활용 방식 ]
  - 거시상태(macrostate) 분포 분석 → Zipf 법칙 확인
  - 엔트로피 분포 분석 → 인간 선택의 무작위성 검증
  - 패턴(연속 숫자, 키보드 배열, 반복 문자 등) 빈도 분석
  - 사용자 입력 비밀번호와 실제 데이터 비교 → 위험도 평가


----------------------------------------------------------------
  페이지 구성
----------------------------------------------------------------

  00. 비밀번호 생성의 원리
      비밀번호 길이, 문자 구성, 엔트로피를 분석하여
      인간이 비밀번호를 만드는 과정을 탐구한다.

  01. 비밀번호의 규칙성
      연속 숫자, 키보드 배열, 날짜 패턴 등을 통해
      인간 선택의 보편적 규칙성을 검증한다.

  02. 비밀번호와 정보보안
      발견된 규칙성이 실제 공격 환경(사전 공격, 브루트포스)에서
      어떤 위험을 만드는지 분석한다.

  03. 비밀번호 안전도 측정
      사용자가 입력한 비밀번호의 희귀도와 안전도를
      실제 데이터와 비교하여 평가한다.
